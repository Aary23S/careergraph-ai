# CareerGraph AI

CareerGraph AI is a career intelligence platform being built progressively from a reliable full-stack MVP toward AI, ML, MLOps, cloud, observability, and production-scale capabilities.

## Phase 0

This repository currently contains the foundation only:

- React frontend
- Node.js + Express backend
- PostgreSQL + Sequelize
- Sequelize migration infrastructure
- Docker Compose
- Environment configuration
- ESLint / Prettier
- Jest / Supertest
- Health endpoint
- Foundation documentation

Product features are intentionally not implemented in Phase 0.

## Repository layout

- `client/` React frontend foundation
- `server/` Express API and PostgreSQL foundation
- `docs/` architecture, API, database, development, and roadmap documentation
- `docker-compose.yml` local multi-service startup
